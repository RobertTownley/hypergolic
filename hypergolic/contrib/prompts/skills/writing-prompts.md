# Skill: Writing Prompts

Applies to every prompt you author: system prompts, roles, skills, workflow states, tool descriptions, /shared docs.

## Police Tokens
- Every always-on line is paid on every message of every session — justify each one
- Prefer on-demand homes (skill, README, /shared doc) over always-on prompt text
- Cut filler: no restating what capable models already do, no "be careful", no adjectives that don't change behavior
- One idea per line; delete any line whose removal changes nothing

## Write for Retrieval
- A description answers *when* to reach for a thing; `--help` and source answer *how*
- Tag with the words a stuck agent would actually search: synonyms, domain nouns, failure symptoms

## Keep It True
- Never document aspiration as fact; a prompt that lies about a path or tool name costs more than it saves
- Point to source files for signatures instead of restating them — restatements drift
- Reread after edits: truncated sentences and stale names survive quick rewrites
